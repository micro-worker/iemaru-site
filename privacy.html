プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-16

日本語

  1. 集める情報：本ツールは、運営者自身の SNS アカウントの、投稿に必要な許可の情報（アクセストークン）と、アカウントの基本情報（表示名・ID）、運営者自身の投稿の数字（再生・いいね・コメント・シェアの数）だけを扱います。
  2. ほかの人の情報：ほかの SNS 利用者の個人情報は集めません。
  3. 使い方：集めた情報は、運営者のアカウントへの投稿と、投稿の成果を見ることだけに使います。
  4. 保管：許可の情報は暗号化して保管し、画面やログに出しません。第三者に渡したり、売ったりしません。
  5. 削除：運営者は、各 SNS の設定から本ツールの許可をいつでも取り消せます。取り消すと、本ツールはそのアカウントの情報を使えなくなります。

English

  1. Information we handle: only the authorization data (access tokens) for the owner's own accounts, basic account information (display name and ID), and performance counts (views, likes, comments, shares) of the owner's own posts.
  2. Other users: no personal data of other social media users is collected.
  3. Use: the information is used only to publish to the owner's accounts and to review the performance of those posts.
  4. Storage: authorization data is stored encrypted and is never displayed or logged. It is never shared with or sold to third parties.
  5. Deletion: the owner can revoke the Tool's access at any time from each platform's settings, after which the Tool can no longer use that account's data.
